# Playbook: Weekly Exec Brief

> Hijack's flagship recurring deliverable. A short Monday brief that frames
> Arthur's week across his investment remit. Modeled on SR's Weekly Team Debrief
> format, but lensed for one principal.

## Trigger

- **Scheduled:** Monday morning (Europe/Zurich), before the Operating Committee
  (Mon 11:00).
- **On demand:** "Generate my weekly exec brief."

## Inputs

- **Deal Flow** — Arthur's deals, grouped by stage; what changed in the last 7
  days; anything dated this week (Deadline, Next Board, Investment Date).
- **SR Meetings** — Arthur's meetings last week (decisions/open points) and this
  week (what needs prep).
- **Tasks / Deliverables** — open items Arthur owns or leads, by priority.
- **Roadmap** — only for framing, if a milestone lands this week.

## Output

Write to the Hijack sandbox page (or Arthur's member page if configured), dated.
Keep it to a ~2-minute read. Structure:

```
# Weekly Exec Brief — week of <YYYY-MM-DD>
> Drafted by Hijack, <date> — review before use.

### 1) Top priorities this week
- 3–5 items, each: what it is · why now · recommended next step.

### 2) Decisions needed from you
- The short list only Arthur can resolve. Link the source page.

### 3) Pipeline pulse
- One line per stage with a count and any notable movement.
- Stale / at-risk deals flagged (see deal-pipeline-review for staleness rules).

### 4) Meetings
- Last week: decisions + open follow-ups.
- This week: meetings needing prep (link to meeting-prep).

### 5) Risks & watch-list
- Blockers, slipping deadlines, KYC/compliance steps pending.
```

## Rules

- Lead with priorities and decisions — the gatekeeping value is deciding what
  reaches Arthur, not listing everything.
- Every item links its source page; no orphan claims.
- If a section has nothing real, write "Nothing this week" — don't pad.
- If a needed surface is empty or unreadable, name it and continue with the rest.

## Quality bar

- Would Arthur know, in two minutes, the 3 things that matter and the decisions
  only he can make? If not, it failed.
- No invented movement. "Changed" means a real, datable change you can point to.
